# Changelog

All notable changes are documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-18

### Added

- reproducible runtime and development locks used by local, CI, and deployment
- one local quality command for formatting, linting, boundary type checks,
  compilation, and deterministic coverage tests
- security policy, AI threat model, contribution guidance, and PR template
- least-privilege immutable workflows and dependency-update automation
- explicit model and system-prompt version identifiers

### Documented

- supported runtime, maturity, architecture, privacy boundaries, limitations,
  release workflow, and manual paid-evaluation boundary
